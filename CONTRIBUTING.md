# Contributing

Thank you for considering contributing!

Local setup

1. Install dependencies:

   pnpm install

2. Run dev server:

   pnpm run dev

Formatting and linting

- Format with Prettier: pnpm run format
- Lint (requires installing ESLint and plugins): pnpm run lint

Tests

- Run tests locally: pnpm run test

Pull requests

- Fork the repo, create a branch, and open a PR with a clear description of the change.
- Include tests for new behavior where applicable.
